# 成绩查询

独立的成绩查询页。页面沿用蓝白渐变、白底表单卡片和成绩表格的布局，不使用任何考试机构的标识或原文案。使用准考证号和姓名查询科目分数、总分、科目排名和总分排名。

## 运行

需要 PHP 8.1 以上，并启用 `pdo_sqlite`。

```bash
php -S 127.0.0.1:8080 -t public
```

浏览器打开 `http://127.0.0.1:8080/`。

首次启动会在 `data/scores.sqlite` 写入 8 名示例考生。例如准考证号 `26010001`、姓名 `陈予安`。

## 排名

- 科目排名：在录入了同一科目的考生中，按该科分数从高到低计算。
- 总分排名：按该考生全部科目分数合计，在所有已有成绩的考生中计算。
- 分数相同则并列，下一名次按人数顺延。

## 成绩维护

管理页：`http://127.0.0.1:8080/admin.php`

初始管理员用户名是 `admin`，初始口令是 `score-admin`。部署后请立即在后台新增管理员、修改初始口令，或在首次运行前替换 `config.php` 的 `admin_password_hash`。

后台登录和前台查询均需要完成算术验证码。后台支持：

- 修改站点标题、页脚文案和查询提示；
- 配置自定义查询字段，例如“证件后四位”；已启用的字段会同时出现在成绩编辑页和前台查询页；
- 新增管理员、修改管理员口令、删除管理员（超级管理员可管理所有管理员）；
- 查看最近 100 条访问日志，包括查询成功、查询失败、验证码失败和管理操作；
- 逐人新增、编辑、删除成绩，也可以粘贴 CSV。

CSV 每行格式：

```text
准考证号,姓名,科目,分数
```
